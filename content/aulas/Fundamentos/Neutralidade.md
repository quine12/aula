O conceito de neutralidade é outro que não é suficientemente enfatizado e este é pedra angular para a construção de toda a álgebra. Todas as operações são definidas ao redor de um **ELEMENTO NEUTRO**

O Elemento neutro é aquele que, para uma determinada operação, **não produz qualquer alteração**. É o elemento neutro que permite espelhar as operações e criar suas contra-partes, ele é o eixo que media o fazer e o desfazer.

Há duas operações básicas necessárias para definir todas as outras. Há duas operações básicas exatamente pois há dois elementos neutros distintos: Soma e Produto.

Para a Soma, o elemento neutro é o 0. Some qualquer algo a 0 e esse algo não se altera.

$$a+0=a$$

$$1+0=1$$

Para o [[Produto]], a multiplicação, o elemento neutro é o um (1). Multiplique qualquer algo por um e esse algo não se altera

$$a*1=a$$

$$4*1=4$$

E, a partir desses elementos neutros, se define novas operações as operações inversas. Operações inversas são aquelas que, quando feitas sob o mesmo valor retornam o elemento neutro.
Para a soma, o inverso é a Subtração;

$$a+(-a)=a-a=-a+a=0$$

Para a multiplicação, o inverso é a  Divisão, veja [[Básicos da Divisão]].

$$b\cdot\frac{1}{b}=\frac{b}{b}=\frac{1}{b}\cdot b=1$$

**Dividir é multiplicar, multiplicar é dividir.**
**Adicionar é subtrair, subtrair é adicionar.**

Funcionalmente, as operações inversas seguem as mesmas regras que as operações básicas e por isso que realizar uma é também realizar a outra.
